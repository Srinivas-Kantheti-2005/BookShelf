# Client Request: BookShelf

**Client:** Srinivas
**Date:** 5 Oct 2026

## Background
I read a lot of books, but I have no single place to track them.
I use notes, screenshots, and memory. I forget what I finished,
what I'm reading, and what I want to read next.

## What I want
A website where I can keep my personal reading library.

- I want to create an account and log in, so my library is private.
- I want to add a book with title, author, and a short description.
- I want to mark each book as: want to read, reading, or finished.
- I want to see all my books in one page and tell the status at a glance.
- I want to edit or delete a book if I made a mistake.
- I want to search my library quickly when it gets big.
- I want to upload a cover picture for each book.
- I want to write personal notes on a book (thoughts, quotes, lessons), as many notes as I want per book.

## Who will use it
Mainly me. Maybe friends later, each with their own library.

## What I do not want (for now)
- No social features (following, sharing, comments).
- No AI chat or recommendations in the first version.
- No mobile app. A website that works on a phone browser is enough.

## Other notes
- It should look clean, like a library or a card catalog.
- It should be fast and not confusing.
- I have no deadline, but I want to see progress step by step.
